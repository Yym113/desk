# 小玉的工作台

一个离线可用的个人工作台，单文件 HTML，双击即开。

## 在线地址

https://yym113.github.io/desk/

## 功能

- 作业管家（交付清单、提交自查、命名生成、创作说明草稿）
- 我的任务 / 日程安排（按天分组，粘贴或截图一键导入）
- 常用网站收藏
- 记账（月账单 / 年账单 / CSV 导出 / 打印）
- 多账户、主题色（8 套预设 + 自定义）、20 个内置头像 + 上传图片
- 6 种界面语言：中文 / English / 日本語 / 한국어 / Español / Français

## 数据说明

所有数据保存在你**自己的浏览器**（localStorage）里，不上传服务器。
换设备或换浏览器看不到原有内容，可用「导出备份 / 导入」搬移。
